## Rationale

**TASK-01** is the only P0 item this report cycle: a guaranteed `NullReferenceException` crash on every returning-player launch when `goalManager` is wired. A two-line null-guard fix unblocks all returning players immediately and carries zero risk of side-effects. It must ship before any other task.

**TASK-02** bundles BUG-NEW-1 and BUG-NEW-2 because both have the same root cause (discarded `ProgressionStore.AddXp` return value) and share the same fix pattern (capture return, propagate to `ApplyLevelReward`). The affected files (`AchievementChecker.cs`, `DailyChallenge.cs`, `TombakanOnboarding.cs`) were all added or modified in the Phase 2.5 / Week 6 passes, so the developer context is fresh. Doing them in one turn avoids opening the same files twice next week.

**TASK-03** addresses two UX correctness issues that can each be fixed in under ten lines. Assigning both to the ui owner is deliberate: the panel-ordering change is pure UI state management inside `TombakanOnboarding`, and the `ShowSad` change corrects display text rather than game logic. Neither touches the game loop or progression data, so the risk profile matches a ui slot.
